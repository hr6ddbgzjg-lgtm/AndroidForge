# Leo Control

Android control layer for the Samsung SM-T350 test tablet.

Current MVP:
- Android 7.0+ compatible
- explicit Accessibility Service permission
- Home / Back / Recents control
- gesture support for taps and swipes
- text entry into focused fields
- active UI-tree reading support for the future agent bridge
- ChatGPT launcher button
- visible on/off status and reversible permissions

This project is intentionally permission-based and visible to the device owner.
